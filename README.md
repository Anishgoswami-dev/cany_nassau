📦 Factory Reallocation & Shipping Optimization Recommendation System
An intelligent decision-support system that optimizes factory allocation and shipping performance using Machine Learning, simulation, and optimization techniques.

🚀 Project Overview
Traditional logistics systems rely on static rules for assigning products to factories. This often results in:

🚚 Longer shipping lead times
💸 Increased operational costs
📉 Reduced profit margins
This project introduces a data-driven approach to improve logistics by predicting outcomes and recommending optimal factory-product assignments.

🎯 Objectives
Predict shipping lead times using machine learning
Simulate different factory allocation scenarios
Recommend optimal product-to-factory assignments
Balance efficiency and profitability
